# GourmetOn – Landing Page
Landing page do app de delivery GourmetOn, com pratos carregados da
API Spoonacular.
**Deploy:** https://gourmeton.vercel.app
## Tecnologias
- React + Vite
- Tailwind CSS
- Fetch API + Spoonacular
- JSON
- React Icons (Font Awesome)
- Vercel
## Como rodar
npm install
npm run dev
(criar um arquivo .env com VITE_SPOONACULAR_KEY=sua_chave)
